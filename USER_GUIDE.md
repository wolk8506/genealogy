# Руководство пользователя — Genealogy

Локальное приложение для семейного древа, фотографий, событий и справочника. Все данные хранятся на вашем компьютере и не отправляются в облако.

---

## Терминология
![Терминология](./guide/10-terminology.png)
_Иллюстрация раздела._

| Термин | Что это |
|--------|---------|
| **Корзина** | Временное удаление (`/trash`): людей и записи справочника можно восстановить |
| **Бэкап / ZIP-бэкап** | Полный экспорт или импорт данных в файл `.zip` |
| **Настройки** | Раздел `/settings` (старый адрес `/archive` перенаправляет сюда) |
| **Справочник** | Люди и питомцы вне семейного древа: кумы, друзья, соседи, животные |
| **Правая панель** | Инспектор выбранной записи: человек, место на карте, фото или точка карты |

---

## Навигация и основные разделы
![Скриншот раздела будет добавлен позже](./guide/11-navigation.png)
_Иллюстрация раздела._

Слева расположено компактное меню разделов. Активный раздел подсвечивается.

| Раздел | Путь | Назначение |
|--------|------|------------|
| **Люди** | `/` | Список родственников, поиск и фильтры |
| **Справочник** | `/external` | Внешние люди и питомцы |
| **Фотогалерея** | `/globalPhotoGallery` | Все фотографии семьи |
| **Карта** | `/map` | Места съёмки и события на карте |
| **Лента** | `/timeline` | Хронология фото и событий |
| **Настройки** | `/settings` | Хранилище, фото, лица, обслуживание |
| **О приложении** | `/about` | Версия, лицензия, история версий и это руководство |

**Верхняя панель** содержит кнопки навигации «Назад/Вперёд», уведомления и инструменты текущего раздела. Если у раздела есть правая панель, в верхней панели появляется кнопка **«Правая панель»** — она открывает и закрывает инспектор.

**Корзина** открывается с главной или из панели справочника (`/trash`, вкладки «Люди» и «Справочник»).

## Главная — список людей
![Главная — список людей](./guide/01-people.png)
_Экран раздела «Люди»._

### 🔍 Назначение

Стартовый экран: все активные (не в корзине) родственники из семейного древа.

### 🖼️ Основные возможности

- **Поиск** по имени, фамилии и ID
- **Фильтры** по меткам, датам редактирования и «В этот день» — фото и события текущей календарной даты
- **Карточка человека** — аватар, имя, даты, переход в профиль
- **Действия** — редактирование, перемещение в корзину, экспорт выбранных
- **Восстановить из бэкапа** — быстрый переход к импорту ZIP
- **Корзина** — счётчик удалённых людей и записей справочника
- **Правая панель** — карточка выбранного человека и связи

### 🧭 Как пользоваться

1. Используйте поиск и фильтры в верхней панели.
2. Клик по карточке открывает страницу человека.
3. Через меню карточки можно отправить человека **в корзину** — это не окончательное удаление.
4. Кнопка **«Добавить человека»** открывает форму новой записи.

## Карточка человека
![Карточка человека](./guide/02-person.png)
_Экран профиля человека._

### 🔍 Назначение

Профиль одного родственника: информация, дерево, биография, события, факты, файлы и личная фотогалерея.

### 🖼️ Основные возможности

- **Информация** — даты, родители, супруги, дети, поколение
- **Семейное дерево** — визуализация связей
- **Биография** — Markdown с вложенными изображениями и поиском по тексту
- **События** — свадьбы, переезды, награды и другие события
- **Факты** — произвольные заметки
- **Файлы** — документы и аудио
- **Фотогалерея** — личный альбом человека
- **Лента этого человека** — переход в «Ленту» с фильтром по ID

### 🧭 Как пользоваться

1. Откройте человека из списка на главной.
2. Переключайтесь между вкладками в верхней панели.
3. Редактирование информации — кнопка карандаша; биография, события и факты редактируются в своих вкладках.

## Добавление человека
![Скриншот раздела будет добавлен позже](./guide/12-add-person.png)
_Иллюстрация раздела._

### 🔍 Назначение

Форма добавляет нового человека в семейное древо: личные данные, даты, поколение и родственные связи.

### 🖼️ Основные возможности

- **Личные данные** — имя, фамилия, девичья фамилия, отчество, пол
- **Даты** — рождение и смерть
- **Поколение** — число ≥ 1
- **Связи** — отец, мать, братья и сёстры, супруг(а), дети
- **Автоматическая связь** — после сохранения связи обновляются с обеих сторон

### 🧭 Как пользоваться

1. Заполните личные данные: пол обязателен, также нужно хотя бы одно из полей имени.
2. При необходимости укажите даты и номер поколения.
3. Настройте родственные связи.
4. Нажмите **«Сохранить»**.

### ⚠️ Ограничения

- Пол обязателен; поколение должно быть числом ≥ 1.
- Девичья фамилия доступна только для женщин.
- Новый человек получает уникальный ID на основе поколения.

## Персональная фотогалерея
![Персональная фотогалерея](./guide/03-person-photos.png)
_Экран личной галереи человека._

### 🔍 Назначение

Альбом конкретного человека: просмотр, группировка, поиск и редактирование связанных фотографий.

### 🖼️ Основные возможности

- **Сетка** — клик по фото открывает полноэкранный просмотр
- **Добавление фото** — файлы, название, описание, #теги, дата, люди и место
- **Группировка** — по дате съёмки или по типу («Мои фотографии» / «Я на фото»)
- **Сортировка** — по возрастанию или убыванию
- **Поиск** — по описанию и тегам
- **Правая панель** — редактирование метаданных выбранного фото
- **Удаление** — доступно владельцу альбома

### 🧭 Как пользоваться

1. Откройте страницу человека → вкладку **«Фото»**.
2. **«Добавить фото»** — выберите файлы и заполните метаданные.
3. Клик по фото — полноэкранный просмотр; кнопка карандаша или контекстное меню → **«Редактировать»** открывает правую панель.
4. Кнопка **«Правая панель»** в верхней панели открывает и закрывает инспектор фото.

### ⚠️ Ограничения

- Удаление доступно владельцу альбома.
- Переименование файла на диске — только при включённой опции в диалоге.

### 📂 Дополнительно

- Фото подгружаются по мере прокрутки (ленивая загрузка).
- Метаданные хранятся в `people/{id}/photos.json`.

## Правая панель фото
![Правая панель фото](./guide/05-photo-panel.png)
_Экран редактирования фото в правой панели._

### 🔍 Назначение

Быстрое редактирование сведений о фотографии без открытия отдельного окна. Одна и та же панель работает в персональной и глобальной галереях.

### 🖼️ Основные возможности

- **Название и описание** — автосохранение при выходе из поля
- **Люди на фото** — родственники и записи справочника
- **Дата съёмки** и **место** — выбор на карте
- **Имя файла** — переименование
- **Лица и превью** — переход к разметке лиц и кадрированию
- **Удаление фото** — для доступных снимков

### 🧭 Как пользоваться

1. Выберите фото в галерее.
2. Откройте панель кнопкой **«Правая панель»** в верхней панели.
3. Измените нужные поля — они сохраняются автоматически.
4. Повторное нажатие кнопки закрывает панель.

## Добавление и редактирование фото
![Скриншот раздела будет добавлен позже](./guide/13-photo-add-edit.png)
_Иллюстрация раздела._

### 🔍 Назначение

Диалог добавления фото собрал в одном месте файл, описание, разметку и параметры сохранения.

_Экран общей галереи всех фотографий._

### 🔍 Назначение

Все фотографии всех людей в одной ленте — удобно искать снимки по дате, человеку или меткам.

## Карта
![Карта](./guide/07-map.png)
_Экран карты с геоточками фото и событий._

### 🔍 Назначение

География семейной истории: места съёмки фотографий и события с координатами.

### 🖼️ Основные возможности

- **Маркеры** — миниатюры фото и иконки событий; группировка снимков по адресу
- **Геокодинг** — определение адреса по GPS с кэшем
- **Правая панель «Точки на карте»** — список точек и детали
- **Попап точки** — фото, переход к человеку, **«Исправить место»**
- **Слои** — родственники и справочник, легенда
- **Фокус по URL** — `/map?focus=…` из ленты или события
- **Shift + «Обновить»** — сброс кэша геокодинга

### 🧭 Как пользоваться

1. Откройте **Карту** и дождитесь построения точек.
2. Клик по маркеру открывает попап; из ленты используйте **«На карте»**.
3. Кнопка **«Правая панель»** показывает список точек.

### ⚠️ Ограничения

- Для геокодинга нужен интернет (Nominatim / OpenStreetMap).
- Фото без координат и события без места на карте не отображаются.

## Справочник: внешние люди и питомцы
![Скриншот раздела будет добавлен позже](./guide/14-external-directory.png)
_Иллюстрация раздела._

### 🔍 Назначение

Справочник хранит людей и питомцев, которые **не входят в семейное древо**, но важны для семейной истории: кумы, друзья, коллеги, соседи, домашние животные.

Данные: `external-entities.json` и папка `external/` в каталоге библиотеки.

### 🖼️ Основные возможности

- **Список** — поиск и фильтр: все / люди / питомцы
- **Карточки** — аватар, тип, связи с древом
- **Добавление и редактирование** — имя, заметки, аватар, связи
- **Правая панель** — детали выбранной записи и быстрые действия
- **Интеграция** — фото, события, карта, лента
- **Корзина** — восстановление и окончательное удаление

### 🧭 Как пользоваться

1. Откройте **Справочник** в меню.
2. Нажмите **«Добавить»**, выберите тип и заполните имя и связи.
3. ID вида `E10001` присваивается автоматически.
4. На фото используйте группу **«Справочник»** в поле людей.

### ⚠️ Ограничения

- Записи не входят в дерево и не участвуют в расчёте поколений.
- **В корзину** — мягкое удаление с возможностью восстановления.
- **Удалить навсегда** — необратимо, очищает ссылки в лицах и связях.

### 📂 Дополнительно

- Справочник входит в ZIP-бэкап и восстанавливается при импорте.
- Уведомления содержат ссылку **«В справочник ▸»**.

## Корзина
![Скриншот раздела будет добавлен позже](./guide/16-trash.png)
_Иллюстрация раздела._

### 🔍 Назначение

Временное хранение удалённых людей и записей справочника до восстановления или окончательного удаления.

### 🖼️ Основные возможности

- **Вкладка «Люди»** — родственники с `archived: true`
- **Вкладка «Справочник»** — записи справочника в корзине (`/trash?tab=external`)
- **Восстановить** — возврат в основной список
- **Удалить навсегда** — каскадная очистка файлов, лиц и меток

### 🧭 Как пользоваться

1. Откройте **Корзину** с главной или из тулбара справочника.
2. Выберите вкладку.
3. Восстановите запись или удалите её навсегда.

### ⚠️ Ограничения

- «В корзину» — это мягкое удаление, а не ZIP-бэкап.
- Полное удаление человека необратимо.

## Настройки. Места хранения данных
![Скриншот раздела будет добавлен позже](./guide/17-storage-paths.png)
_Иллюстрация раздела._

### 🔍 Назначение

Карточка **«Места хранения данных»** позволяет держать несколько корней библиотеки, например локальную папку и внешний диск. Переключение активного места перезапускает приложение.

### 🖼️ Основные возможности

- Список известных папок и добавление через диалог
- Переключение активного корня
- Проверка свободного места (минимум около 500 МБ)
- Автоматический откат на стандартный путь, если диск недоступен

### 🧭 Как пользоваться

1. **Настройки** → **Хранилище и данные** → карточка мест хранения.
2. **Добавить папку** — укажите каталог.
3. **Сделать активной** — подтвердите перезапуск.

### ⚠️ Ограничения

- Одновременно активен только один корень.
- Перед импортом большого бэкапа проверяйте свободное место.

## Настройки. Экспорт и импорт бэкапа
![Скриншот раздела будет добавлен позже](./guide/18-backup-import-export.png)
_Иллюстрация раздела._

### 🔍 Назначение

Карточка **«Статистика хранилища»** показывает занятое место и содержит блок **«Импорт / экспорт данных»** для полного ZIP-бэкапа.

### 🖼️ Основные возможности

**Экспорт:**

- Имя файла и выбор папок фото (`original`, `webp`, `thumbs`)
- Опционально: метки (`tags.json`), журнал действий (`history.jsonl`)
- Опционально: `VACUUM + ANALYZE` SQLite перед упаковкой
- В ZIP: `genealogy-data.json`, `manifest.json`, люди, справочник, SQLite, фото

**Импорт:**

- Выбор ZIP-бэкапа и просмотр содержимого
- Выбор восстанавливаемых папок и дополнительных данных
- Разрешение конфликтов ID: обновить / пропустить / только новые
- Объединение меток и дописывание журнала

### 🧭 Как пользоваться

1. **Настройки** → **Хранилище и данные** → статистика.
2. **Экспорт** → настройте параметры → **Создать бэкап** → укажите путь к `.zip`.
3. **Импорт** → выберите ZIP → проверьте параметры → **Восстановить**.
4. После импорта проверьте справочник и галереи.

### ⚠️ Ограничения

- Старые бэкапы без `external-entities.json` восстанавливают только родственников.
- Импорт меток и журнала зависит от наличия файлов в ZIP.
- Записи справочника объединяются по ID, а не заменяют весь справочник.

### 📂 Дополнительно

- Формат `genealogy-data.json`: `{ "schemaVersion": 1, "people": [...] }`; старые файлы-массивы читаются автоматически.
- Manifest v2 содержит флаги `includeTags` и `includeHistory`.

## Настройки. Обслуживание медиа
![Скриншот раздела будет добавлен позже](./guide/19-media-maintenance.png)
_Иллюстрация раздела._

### 🔍 Назначение

Карточка **«Обслуживание медиа»** выполняет пакетные операции над фотографиями и базой.

### 🖼️ Основные возможности

## Настройки. Распознавание и проверка лиц
![Скриншот раздела будет добавлен позже](./guide/20-face-recognition.png)
_Иллюстрация раздела._

### 🔍 Назначение

Локальное сканирование библиотеки фотографий: поиск лиц и предложение подписей. Подтверждение всегда выполняется вручную.

### 🖼️ Основные возможности

- **Мастер сканирования** — режимы «Только рамки» и «Рамки + подпись», порог, область поиска, пауза и возобновление
- **Очередь проверки** — отдельная страница с фото и подсказками
- **Фото без лиц** — отдельная страница для снимков, где лица не найдены
- **Действия на фото** — авто-поиск лиц и подсказка по управлению рамками
- **Пересборка face references** — обновление эталонных дескрипторов

### 🧭 Как пользоваться

1. Разметьте 20–50 опорных фото или используйте аватары.
2. **Настройки** → **Распознавание лиц** → настройте и запустите сканирование.
3. Откройте **«Очередь проверки»** и подтвердите или исправьте подписи.
4. Для снимков без лиц откройте **«Фото без лиц»**.

### ⚠️ Ограничения

- Всё выполняется на вашем компьютере; модели загружаются при первом сканировании.
- Первый полный прогон большой коллекции может занять 30–60+ минут.
- Автоподпись не применяется без подтверждения.

## Настройки. Опасная зона
![Скриншот раздела будет добавлен позже](./guide/21-danger-zone.png)
_Иллюстрация раздела._

### 🔍 Назначение

Необратимые операции: удаление медиа и полный сброс библиотеки.

### 🖼️ Основные возможности

- Удаление **оригиналов** или **кэша** (webp/thumbs) без удаления людей
- **Полный сброс** — очистка активной папки данных с подтверждением

### ⚠️ Ограничения

- Полный сброс удаляет людей, фото, справочник и SQLite без восстановления, если нет бэкапа.
- Перед сбросом сделайте ZIP-бэкап, если данные важны.

### 🧭 Как пользоваться

1. **Настройки** → **Опасная зона**.
2. Сначала создайте **ZIP-бэкап**.
3. Выполните действие и подтвердите его.

## Структура данных на диске
![Скриншот раздела будет добавлен позже](./guide/22-disk-structure.png)
_Иллюстрация раздела._

Типичная папка библиотеки (активный корень):

```
Genealogy/
├── genealogy-data.json      # люди (schemaVersion + people)
├── external-entities.json   # справочник
├── tags.json                # метки
├── history.jsonl            # журнал действий
├── genealogy.sqlite         # лица, кэш геокодинга
├── people/
│   └── {id}/
│       ├── photos.json
│       ├── bio.md
│       ├── avatar.jpg
│       ├── files/
│       └── photos/
│           ├── original/
│           ├── webp/
│           └── thumbs/
└── external/
    └── {id}/
        └── avatar.jpg
```

По умолчанию используется `Documents/Genealogy`; активное место можно изменить в настройках.
