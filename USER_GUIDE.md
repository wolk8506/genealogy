## Добавление человека

### 🔍 Назначение

Страница **Добавления человека** предназначена для внесения новых людей в семейное древо. Она позволяет указать личные данные, даты рождения и смерти, поколение, а также настроить родственные связи (родители, супруги, дети, братья/сёстры). После сохранения новый человек автоматически добавляется в базу и связывается с другими.

---

### 🖼️ Основные возможности

- **Ввод личных данных**

   - Имя
   - Фамилия
   - Девичья фамилия (активна только для женщин)
   - Отчество
   - Пол (обязательное поле)

- **Указание дат**

   - Дата рождения
   - Дата смерти
   - Поколение (число ≥ 1)

- **Настройка родственных связей**

   - Отец (выбирается из мужчин предыдущего поколения)
   - Мать (выбирается из женщин предыдущего поколения)
   - Братья/сёстры (выбираются из текущего поколения)
   - Супруг(а) (выбирается из текущего поколения противоположного пола)
   - Дети (выбираются из следующего поколения)

- **Сохранение**

   - После нажатия кнопки **«Сохранить»** новый человек добавляется в базу.
   - Автоматически обновляются связи:
      - Родители получают ссылку на ребёнка.
      - Дети получают ссылку на родителя.
      - Супруги связываются взаимно.
      - Братья/сёстры связываются взаимно.

---

### 🧭 Как пользоваться

1. Заполните личные данные (имя, фамилия, отчество, пол).
2. Укажите даты рождения и смерти (при необходимости).
3. Введите номер поколения (например, 1 для первого поколения).
4. Настройте родственные связи:
   - Выберите родителей из предыдущего поколения.
   - Добавьте братьев/сестёр из текущего поколения.
   - Укажите супругов из текущего поколения.
   - Добавьте детей из следующего поколения.

5. Нажмите кнопку **«Сохранить»**.
6. После сохранения появится уведомление об успешном добавлении.

---

### ⚠️ Ограничения

- Пол обязателен для заполнения.
- Поколение должно быть числом ≥ 1.
- Нужно указать хотя бы одно из полей: имя, фамилия, отчество или девичья фамилия.
- Девичья фамилия доступна только для женщин.
- Если файл данных не может быть сохранён, появится сообщение об ошибке.

---

### 📂 Дополнительно

- После сохранения форма очищается, и можно сразу добавить следующего человека.
- Новый человек получает уникальный ID, который формируется автоматически на основе поколения.
- Все изменения сохраняются в общей базе (`peopleAPI.saveAll`).

## Страница пользователя. Фотогалерея

### 🔍 Назначение

Фотогалерея предназначена для просмотра, сортировки и редактирования фотографий, связанных с конкретным человеком. Она позволяет добавлять новые фото, просматривать их в сетке или на весь экран, редактировать метаданные и удалять ненужные снимки.

---

### 🖼️ Основные возможности

- **Просмотр фотографий**

   - Все фото отображаются в виде сетки.
   - При клике на фото оно открывается в полноэкранном режиме с возможностью перелистывания.

- **Добавление фото**

   - Кнопка **«Добавить фото»** открывает диалог загрузки.
   - После загрузки фото автоматически появляется в галерее.
   - В диалоге можно указать:
      - заголовок, описание и #теги,
      - **кто на фото** — родственники из семейного древа,
      - **из справочника (внешние)** — кумы, друзья, питомцы и др.,
      - **разметку лиц** (рамки, подписи, авто-поиск),
      - дату съёмки.

- **Сортировка**

   - Кнопка **«Сортировать по дате»** меняет порядок фотографий:
      - по дате добавления,
      - по дате съёмки (новые/старые).

- **Редактирование фото**

   - Кнопка ✏️ (карандаш) на фото открывает диалог редактирования.
   - В диалоге можно изменить:
      - заголовок,
      - описание,
      - список людей на фото (родственники),
      - **записи из справочника** (внешние люди и питомцы),
      - **разметку лиц** (рамки, подписи, авто-поиск; выбор из групп «Родственники» / «Справочник»),
      - дату съёмки,
      - формат отображения (горизонтальное, квадратное, вертикальное),
      - имя файла (с переименованием на диске).

   - **Управление рамками лиц в редакторе:**
      - **Рамка** — режим рисования новой рамки (ЛКМ + перетаскивание)
      - **Найти** — авто-поиск всех лиц на фото
      - **ЛКМ** по рамке — выбор лица
      - **ПКМ + перетаскивание** — перемещение выбранной рамки
      - Кнопка **«i»** — подсказка по управлению

   - После сохранения изменения применяются сразу.

- **Удаление фото**

   - Кнопка 🗑️ (корзина) доступна владельцу фото.
   - При удалении фото исчезает из галереи и JSON‑данных.

- **Полноэкранный режим**

   - При клике на фото открывается слайдер на весь экран.
   - Можно перелистывать стрелками ← → или свайпами.
   - Есть кнопка выхода из полноэкранного режима.
   - Кнопка **лица** включает отображение рамок (по умолчанию скрыты).
   - В полноэкранном режиме отображаются:
      - заголовок и описание,
      - дата съёмки,
      - кто изображён на фото (родственники и записи из справочника).

## Справочник (внешние люди и питомцы)

### 🔍 Назначение

**Справочник** хранит людей и питомцев, которые **не входят в семейное древо**, но важны для семейной истории: кумы, друзья, коллеги, соседи, домашние животные и т.п. Записи справочника можно отмечать на фото, добавлять в события и связывать с родственниками из древа.

Данные хранятся отдельно от основной базы: файл `external-entities.json` и папка `external/` в каталоге Genealogy.

---

### 🖼️ Основные возможности

- **Список записей**

   - Поиск по имени
   - Фильтр: все / люди / питомцы
   - Карточки с аватаром, типом и кратким описанием связей

- **Добавление и редактирование**

   - Тип: **человек** или **питомец**
   - Имя, заметки, аватар
   - **Связи с древом** — привязка к родственнику, тип связи (кум, друг, сосед и др.), даты, комментарий

- **Карточка записи**

   - Просмотр и редактирование данных
   - Загрузка и обрезка аватара
   - Удаление записи

- **Интеграция с фото и событиями**

   - Отметка на фото при добавлении и редактировании
   - Подписи на рамках лиц в галерее и полноэкранном просмотре
   - Участники событий на странице человека

---

### 🧭 Как пользоваться

1. Откройте **Справочник** через боковое меню или кнопку на панели списка людей.
2. Нажмите **«Добавить»**, выберите тип (человек / питомец), заполните имя и при необходимости связи с родственниками.
3. Сохраните запись — ей будет присвоен ID вида `E10001`.
4. При добавлении или редактировании фото выберите запись в поле **«Из справочника (внешние)»** или привяжите лицо в разметке (группа **«Справочник»**).
5. В редакторе событий добавьте участника из справочника через общий список участников.

---

### ⚠️ Ограничения

- Записи справочника **не отображаются** в дереве родственников и не участвуют в расчёте поколений.
- ID записей начинаются с `E`, чтобы не пересекаться с ID людей в древе.
- Удаление записи необратимо (фото сохранят ссылку на ID, но имя может не отображаться).

---

### 📂 Дополнительно

- Справочник **включается в полный архив** при экспорте и **восстанавливается** при импорте ZIP.
- В уведомлениях о записях справочника доступна ссылка **«В справочник ▸»**.

## События. Участники из справочника

### 🔍 Назначение

При создании или редактировании **события** на странице человека можно указать не только родственников из древа, но и людей (или питомцев) из **справочника** — например, кумов на крестинах, друзей на свадьбе.

---

### 🖼️ Основные возможности

- Единый список участников с группами **«Родственники»** и **«Справочник»**
- На странице событий участники из справочника отображаются с аватаром и ссылкой на карточку записи

---

### 🧭 Как пользоваться

1. Откройте страницу человека → раздел **События**.
2. Создайте или отредактируйте событие.
3. В поле **Участники** выберите нужных родственников и/или записи из справочника.
4. Сохраните событие.

## Настройки. Экспорт и импорт архива

### 🔍 Назначение

Карточка **«Статистика и архив»** в настройках позволяет создать полный ZIP-бэкап всех данных и восстановить их из архива.

---

### 🖼️ Основные возможности

- **Полный экспорт**

   - Семейное древо (`genealogy-data.json`)
   - Папки людей с фото, биографиями и файлами
   - **Справочник** (`external-entities.json` и аватары в `external/`)
   - Уведомление с числом записей справочника в архиве

- **Полный импорт**

   - Восстановление людей и их файлов
   - **Восстановление справочника** (записи объединяются с локальным справочником по ID)
   - Уведомление о числе восстановленных записей и файлов справочника

---

### 🧭 Как пользоваться

1. Откройте **Настройки** → карточка со статистикой и архивом.
2. **Сохранить полный архив** — выберите место для ZIP-файла, дождитесь завершения.
3. **Восстановить из архива** — выберите ZIP, при конфликтах ID людей укажите действие (обновить / пропустить / только новые).
4. После импорта проверьте раздел **Справочник** и галереи фото.

---

### ⚠️ Ограничения

- Архив без `external-entities.json` (старые бэкапы) восстанавливает только родственников — это нормально.
- При импорте записи справочника **объединяются** с существующими (по ID), а не заменяют весь справочник целиком.

## Настройки. Распознавание лиц

### 🔍 Назначение

Карточка **«Распознавание лиц»** в настройках предназначена для пакетного локального сканирования архива фото (~10 000 и более), поиска лиц и предложения подписей. Подтверждение подписи выполняется вручную в очереди проверки.

---

### 🖼️ Основные возможности

- **Мастер сканирования**

   - Режим «Только рамки» — находит лица без предложения подписи
   - Режим «Рамки + подпись» — предлагает человека из эталонов (размеченные лица и аватары)
   - Пропуск фото, где уже есть рамки
   - Фильтр по владельцам (папкам людей)
   - Прогресс, пауза и остановка; состояние сохраняется для возобновления

- **Очередь проверки**

   - Открывается из карточки или из уведомлений
   - Показывает только фото с неподписанными лицами
   - Кнопки: **Принять предложение**, выбор другого человека, **Пропустить**, **Удалить рамку**

- **Объединение похожих лиц**

   - Находит группы, где один человек размечен разными людьми на разных фото
   - Позволяет выбрать правильного человека и перепривязать все лица группы

---

### 🧭 Как пользоваться

1. Разметьте 20–50 «опорных» фото вручную (или используйте аватары) — от этого зависит качество предложений.
2. Откройте **Настройки** → **Распознавание лиц** → **Настроить сканирование**.
3. Выберите режим и запустите сканирование.
4. После завершения откройте **Очередь проверки** и подтвердите подписи.
5. При необходимости используйте **Объединить похожие лица** для исправления ошибочно разделённых людей.

---

### ⚠️ Ограничения

- Распознавание выполняется **локально** на вашем компьютере.
- Первый полный прогон большого архива может занять 30–60 минут и более.
- Автоматическая подпись не применяется — только предложение; финальное решение за пользователем.

---

---

### 📂 Дополнительные функции

- **Загрузка путей к фото** выполняется автоматически при прокрутке галереи — фотографии подгружаются по мере появления в зоне видимости.
- **Наведение на фото** показывает оверлей с описанием и списком людей.
- **Индикатор загрузки** отображается, если фото ещё не успело подгрузиться.

---

### 🧭 Как пользоваться

1. Откройте страницу человека — галерея загрузится автоматически.
2. Для добавления фото нажмите кнопку **«Добавить фото»**; при необходимости отметьте родственников и записи из **справочника**.
3. Чтобы отредактировать фото, наведите курсор и нажмите ✏️.
4. Чтобы удалить фото, нажмите 🗑️ (доступно владельцу).
5. Для просмотра фото в большом размере просто кликните по нему.
6. В полноэкранном режиме используйте стрелки или свайпы для перелистывания.
7. Для сортировки нажмите кнопку **«Сортировать по дате»**.

---

### ⚠️ Ограничения

- Удаление фото доступно только владельцу.
- Переименование файла работает только если включена опция «Переименовать» в диалоге редактирования.
- Если файл не удаётся переименовать на диске, изменения всё равно сохраняются в JSON и интерфейсе, но физическое имя файла остаётся прежним.
