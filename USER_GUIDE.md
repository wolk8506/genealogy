## Терминология

| Термин | Что это |
|--------|---------|
| **Корзина** | Временное удаление (`/trash`): люди и записи справочника можно восстановить |
| **Бэкап / ZIP-бэкап** | Полный экспорт или импорт данных в файл `.zip` |
| **Настройки** | Раздел `/settings` (старый адрес `/archive` перенаправляет сюда) |
| **Справочник** | Люди и питомцы вне семейного древа (кумы, друзья, животные) |

## Навигация и основные разделы

Боковое меню приложения:

| Раздел | Путь | Назначение |
|--------|------|------------|
| **Люди** | `/` | Список родственников, поиск, фильтры |
| **Справочник** | `/external` | Внешние записи (не в древе) |
| **Фотогалерея** | `/globalPhotoGallery` | Все фото семьи в одном месте |
| **Карта** | `/map` | Места съёмки и события на карте |
| **Лента** | `/timeline` | Хронология фото и событий |
| **Настройки** | `/settings` | Хранилище, бэкап, лица, обслуживание |
| **О приложении** | `/about` | Версия, лицензия, changelog |

**Корзина** открывается с главной или из панели справочника (`/trash`, вкладки «Люди» и «Справочник»).

Справа может отображаться **панель инспектора** (детали выбранной записи справочника или точки на карте).

## Главная — список людей

### 🔍 Назначение

Стартовый экран: все активные (не в корзине) родственники из семейного древа.

### 🖼️ Основные возможности

- **Поиск** по имени, фамилии, ID
- **Фильтры** по меткам (tags), датам редактирования, «В этот день» (фото и события в текущую календарную дату)
- **Карточка человека** — аватар, имя, даты, переход в профиль
- **Действия** — редактирование, перемещение в корзину, экспорт выбранных
- **Восстановить из бэкапа** — быстрый переход к импорту ZIP (если база пуста или нужен перенос)
- **Корзина** — индикатор числа удалённых людей и записей справочника

### 🧭 Как пользоваться

1. Используйте строку поиска в верхней панели.
2. Клик по карточке открывает страницу человека.
3. Через меню карточки можно отправить человека **в корзину** (не окончательное удаление).
4. Кнопка **«Добавить человека»** открывает форму новой записи.

## Карточка человека

### 🔍 Назначение

Профиль одного родственника: биография, дерево, события, факты, файлы и личная фотогалерея.

### 🖼️ Основные возможности

- **Информация** — даты, родители, супруги, дети, поколение
- **Семейное дерево** — визуализация связей
- **Биография** — Markdown с вложенными изображениями
- **События** — свадьбы, переезды, награды и др.
- **Факты** — произвольные заметки
- **Файлы** — документы и аудио
- **Фотогалерея** — см. [отдельный раздел](#страница-пользователя-фотогалерея)
- **Лента этого человека** — переход в раздел «Лента» с фильтром по ID

### 🧭 Как пользоваться

1. Откройте человека из списка на главной.
2. Переключайтесь между вкладками (инфо, биография, события, фото и т.д.).
3. Редактирование — через кнопку карандаша или соответствующие диалоги.

## Добавление человека

### 🔍 Назначение

Страница **Добавления человека** предназначена для внесения новых людей в семейное древо. Она позволяет указать личные данные, даты рождения и смерти, поколение, а также настроить родственные связи (родители, супруги, дети, братья/сёстры). После сохранения новый человек автоматически добавляется в базу и связывается с другими.

### 🖼️ Основные возможности

- **Ввод личных данных**

   - Имя
   - Фамилия
   - Девичья фамилия (активна только для женщин)
   - Отчество
   - Пол (обязательное поле)

- **Указание дат**

   - Дата рождения
   - Дата смерти
   - Поколение (число ≥ 1)

- **Настройка родственных связей**

   - Отец (выбирается из мужчин предыдущего поколения)
   - Мать (выбирается из женщин предыдущего поколения)
   - Братья/сёстры (выбираются из текущего поколения)
   - Супруг(а) (выбирается из текущего поколения противоположного пола)
   - Дети (выбираются из следующего поколения)

- **Сохранение**

   - После нажатия кнопки **«Сохранить»** новый человек добавляется в базу.
   - Автоматически обновляются связи:
      - Родители получают ссылку на ребёнка.
      - Дети получают ссылку на родителя.
      - Супруги связываются взаимно.
      - Братья/сёстры связываются взаимно.

### 🧭 Как пользоваться

1. Заполните личные данные (имя, фамилия, отчество, пол).
2. Укажите даты рождения и смерти (при необходимости).
3. Введите номер поколения (например, 1 для первого поколения).
4. Настройте родственные связи.
5. Нажмите **«Сохранить»**.

### ⚠️ Ограничения

- Пол обязателен для заполнения.
- Поколение должно быть числом ≥ 1.
- Нужно указать хотя бы одно из полей: имя, фамилия, отчество или девичья фамилия.
- Девичья фамилия доступна только для женщин.

### 📂 Дополнительно

- Новый человек получает уникальный ID на основе поколения.
- Данные сохраняются в `genealogy-data.json`.

## Страница пользователя. Фотогалерея

### 🔍 Назначение

Фотогалерея предназначена для просмотра, сортировки и редактирования фотографий, связанных с конкретным человеком.

### 🖼️ Основные возможности

- **Просмотр** — сетка; клик открывает полноэкранный слайдер
- **Добавление фото** — заголовок, описание, #теги, дата съёмки, участники (родственники и справочник), разметка лиц
- **Сортировка** — по дате добавления или дате съёмки
- **Редактирование** — метаданные, люди на фото, рамки лиц, формат отображения, переименование файла
- **Удаление** — кнопка 🗑️ у владельца альбома

**Управление рамками лиц в редакторе:**

- **Рамка** — рисование новой рамки (ЛКМ + перетаскивание)
- **Найти** — авто-поиск лиц
- **ЛКМ** по рамке — выбор; **ПКМ + перетаскивание** — перемещение
- Кнопка **«i»** — подсказка

**Полноэкранный режим:**

- Стрелки ← → или свайпы; Esc — выход
- Клавиша **F** — полноэкранный режим окна
- Кнопка **лица** — показ/скрытие рамок
- **Редактировать** — переход в диалог метаданных
- Скачивание текущего снимка

### 🧭 Как пользоваться

1. Откройте страницу человека → вкладка с фото.
2. **«Добавить фото»** — выберите файлы и заполните метаданные.
3. Наведите на фото → ✏️ для редактирования, 🗑️ для удаления.
4. Клик по фото — полноэкранный просмотр.

### ⚠️ Ограничения

- Удаление доступно владельцу альбома (человек, чья это папка).
- Переименование файла на диске — только при включённой опции в диалоге.

### 📂 Дополнительно

- Фото подгружаются при прокрутке (ленивая загрузка).
- Метаданные хранятся в `people/{id}/photos.json`.

## Глобальная фотогалерея

### 🔍 Назначение

Все фотографии всех людей в одной ленте — удобно искать снимки по дате, человеку или меткам.

### 🖼️ Основные возможности

- **Группировка** — по дате съёмки или по людям (владельцам альбомов)
- **Скраббер** (шкала справа) — быстрая навигация по временной шкале; heatmap плотности фото; превью при перетаскивании
- **Фильтр по человеку** — в панели инструментов
- **Полноэкранный просмотр** — как в личной галерее

### 🧭 Как пользоваться

1. Откройте **Фотогалерея** в боковом меню.
2. Выберите режим группировки в тулбаре.
3. Перетаскивайте маркер на скраббере для быстрого перехода к нужному периоду.

### 📂 Дополнительно

- При группировке «Дата снимка» вертикальный scrollbar списка скрыт — навигация через скраббер.

## Лента времени

### 🔍 Назначение

Хронологический обзор: фото, события родственников и записи справочника (по датам рождения и др.).

### 🖼️ Основные возможности

- **Уровни** — Годы → Месяцы → Дни (с виртуализацией длинных списков)
- **Фильтры** — по человеку («Лента этого человека»), слой справочника (**Спр.**)
- **Скраббер** на уровне «Дни» — быстрый переход по шкале
- **Диалог события** — участники, место, кнопка **«На карте»**
- **Слайдер фото** — клавиши ←/→, Esc, F, редактирование метаданных, скачивание
- **URL-состояние** — `?level=&year=&month=&person=` для закладок и кнопки «Назад» браузера

### 🧭 Как пользоваться

1. Откройте **Лента** в меню.
2. Спуститесь от уровня «Годы» к «Дням».
3. Клик по событию — диалог с деталями; клик по фото — полноэкранный просмотр.
4. С карточки человека на главной — **«Лента этого человека»** открывает ленту с фильтром.

## Карта

### 🔍 Назначение

География семейной истории: места съёмки фото и события с координатами.

### 🖼️ Основные возможности

- **Маркеры** — миниатюры фото, иконки событий; группировка нескольких снимков по одному адресу
- **Геокодинг** — автоматическое определение адреса по GPS (с кэшем и ETA в тулбаре)
- **Боковая панель «Точки на карте»** — список точек; клик **центрирует карту** (без открытия фото)
- **Попап точки** — просмотр фото, переход к человеку, **«Исправить место»**
- **Слои** — родственники, справочник; легенда слоёв
- **Фокус по URL** — `/map?focus=…` из ленты или диалога события
- **Shift + «Обновить»** — сброс geocode-кэша

### 🧭 Как пользоваться

1. Откройте **Карта**.
2. Дождитесь построения точек (при необходимости — геокодинг в фоне).
3. Клик по маркеру — попап; из ленты — **«На карте»** для перехода с фокусом.

### ⚠️ Ограничения

- Для геокодинга нужен интернет (Nominatim / OpenStreetMap).
- Фото без координат и события без места на карте не отображаются.

## Справочник (внешние люди и питомцы)

### 🔍 Назначение

**Справочник** хранит людей и питомцев, которые **не входят в семейное древо**, но важны для семейной истории: кумы, друзья, коллеги, соседи, домашние животные. Записи можно отмечать на фото, добавлять в события и связывать с родственниками.

Данные: `external-entities.json` и папка `external/` в каталоге библиотеки.

### 🖼️ Основные возможности

- **Список** — поиск, фильтр: все / люди / питомцы
- **Карточки** — аватар, тип, связи с древом
- **Добавление и редактирование** — имя, заметки, аватар, связи (кум, друг, сосед…)
- **Правая панель инспектора** — детали выбранной записи, быстрые действия
- **Маршруты** — `/external` (список), `/external/:id` (полная страница), `?selected=` для выделения
- **Интеграция** — фото, события, карта, лента

### 🧭 Как пользоваться

1. Откройте **Справочник** в меню.
2. **«Добавить»** → тип (человек / питомец) → имя и связи.
3. ID вида `E10001` присваивается автоматически.
4. На фото — поле **«Из справочника»** или группа **«Справочник»** в разметке лиц.

### ⚠️ Ограничения

- Записи **не в дереве** и не участвуют в расчёте поколений.
- **В корзину** — soft delete, восстановление возможно.
- **Удалить навсегда** — необратимо (очищаются ссылки в лицах и связях).

### 📂 Дополнительно

- Справочник **входит в ZIP-бэкап** и восстанавливается при импорте.
- Уведомления содержат ссылку **«В справочник ▸»**.

## События. Участники из справочника

### 🔍 Назначение

При создании или редактировании **события** на странице человека можно указать родственников из древа и людей (или питомцев) из **справочника** — кумов на крестинах, друзей на свадьбе и т.д.

### 🖼️ Основные возможности

- Единый список участников: **«Родственники»** и **«Справочник»**
- Отображение на странице событий с аватаром и ссылкой на карточку

### 🧭 Как пользоваться

1. Страница человека → **События**.
2. Создайте или отредактируйте событие.
3. В **Участники** выберите нужных людей.
4. Сохраните.

## Корзина

### 🔍 Назначение

Временное хранение удалённых **людей** и записей **справочника** перед восстановлением или окончательным удалением.

### 🖼️ Основные возможности

- **Вкладка «Люди»** — родственники с `archived: true`
- **Вкладка «Справочник»** — записи справочника в корзине (`/trash?tab=external`)
- **Восстановить** — возврат в основной список
- **Удалить навсегда** — каскадная очистка файлов, лиц в SQLite, меток

### 🧭 Как пользоваться

1. Откройте **Корзину** с главной или из тулбара справочника.
2. Выберите вкладку.
3. **Восстановить** или **Удалить навсегда** на карточке.

### ⚠️ Ограничения

- «В корзину» с главной — это не ZIP-бэкап и не настройки; это soft delete.
- Полное удаление человека необратимо.

## Настройки. Места хранения данных

### 🔍 Назначение

Карточка **«Места хранения данных»** — несколько корней библиотеки (например, `C:/Genealogy` и внешний диск). Переключение активного места перезапускает приложение.

### 🖼️ Основные возможности

- Список известных папок, добавление через диалог
- Переключение активного корня
- Проверка свободного места (минимум ~500 МБ) перед переключением
- Авто-откат на стандартный путь, если диск недоступен

### 🧭 Как пользоваться

1. **Настройки** → **Хранилище и данные** → карточка мест хранения.
2. **Добавить папку** — укажите каталог (пустой или существующая библиотека).
3. **Сделать активной** — подтвердите перезапуск.

### ⚠️ Ограничения

- Одновременно активен один корень.
- Перед импортом большого бэкапа проверяйте свободное место на диске.

## Настройки. Экспорт и импорт бэкапа

### 🔍 Назначение

Карточка **«Статистика хранилища»** показывает занятое место и содержит блок **«Импорт / экспорт данных»** для полного ZIP-бэкапа.

### 🖼️ Основные возможности

**Экспорт (кнопка «Экспорт»):**

- Параметры бэкапа: имя файла, папки фoto (`original`, `webp`, `thumbs`)
- Опционально: **метки** (`tags.json`), **журнал действий** (`history.jsonl`)
- Опционально: **VACUUM + ANALYZE** SQLite перед упаковкой
- В ZIP: `genealogy-data.json`, `manifest.json`, люди, справочник, SQLite, фото

**Импорт (кнопка «Импорт»):**

- Выбор ZIP-бэкапа, просмотр содержимого
- Выбор восстанавливаемых папок фото и доп. данных
- Разрешение конфликтов ID (обновить / пропустить / только новые)
- Merge меток и дописывание журнала

### 🧭 Как пользоваться

1. **Настройки** → **Хранилище и данные** → статистика.
2. **Экспорт** → настройте параметры → **Создать бэкап** → укажите путь для `.zip`.
3. **Импорт** → выберите ZIP → проверьте параметры → **Восстановить**.
4. После импорта проверьте **Справочник** и галереи.

### ⚠️ Ограничения

- Старые бэкапы без `external-entities.json` восстанавливают только родственников.
- Старые бэкапы без флагов `includeTags` / `includeHistory` — импорт меток и журнала по наличию файла в ZIP.
- Записи справочника **объединяются** по ID, а не заменяют весь справочник.

### 📂 Дополнительно

- Формат `genealogy-data.json`: `{ "schemaVersion": 1, "people": [...] }` (старые файлы-массивы читаются автоматически).
- Manifest v2: флаги `includeTags`, `includeHistory`.

## Настройки. Обслуживание медиа

### 🔍 Назначение

Карточка **«Обслуживание медиа»** — пакетные операции над фото и базой: конвертация, очистка, аудит, задачи SQLite.

### 🖼️ Основные возможности (примеры задач)

- Конвертация в WebP и генерация превью
- Очистка битых ссылок в `photos.json`
- Удаление дубликатов записей в JSON
- Гео-патчер — подстановка адресов по GPS
- Аудит расхождений JSON ↔ файлы на диске
- **SQLite**: статистика, VACUUM + ANALYZE, integrity check

### 🧭 Как пользоваться

1. **Настройки** → **Фотографии** → **Обслуживание медиа**.
2. Выберите задачу и запустите.
3. Следите за логом выполнения в карточке.

### ⚠️ Ограничения

- Гео-патчер обращается к интернету (Nominatim); между запросами пауза.
- Тяжёлые задачи лучше запускать при закрытых других операциях импорта.

## Настройки. Распознавание лиц

### 🔍 Назначение

Пакетное **локальное** сканирование библиотеки фото (~10 000 и более): поиск лиц и предложение подписей. Подтверждение — только вручную.

### 🖼️ Основные возможности

- **Мастер сканирования** — «Только рамки» / «Рамки + подпись»; фильтр по людям; пауза и возобновление
- **Очередь проверки** — принять, выбрать другого, пропустить, удалить рамку
- **Объединение похожих лиц** — исправление ошибочно разделённых людей

### 🧭 Как пользоваться

1. Разметьте 20–50 опорных фото или используйте аватары.
2. **Настройки** → **Распознавание лиц** → настройте и запустите сканирование.
3. **Очередь проверки** — подтвердите подписи.
4. При необходимости — **Объединить похожие лица**.

### ⚠️ Ограничения

- Всё выполняется на вашем компьютере; модели загружаются при первом сканировании.
- Первый полный прогон большой коллекции может занять 30–60+ минут.
- Автоподпись не применяется без вашего подтверждения.

## Настройки. Опасная зона

### 🔍 Назначение

Необратимые операции: удаление медиа и полный сброс библиотеки.

### 🖼️ Основные возможности

- Удаление **оригиналов** или **кэша** (webp/thumbs) без удаления людей
- **Полный сброс** — очистка всей активной папки данных (с подтверждением текстом)

### ⚠️ Ограничения

- Полный сброс удаляет людей, фото, справочник, SQLite — **без восстановления**, если нет бэкапа.
- Перед сбросом SQLite закрывается корректно; после успешного сброса создаётся пустая база.

### 🧭 Как пользоваться

1. **Настройки** → **Опасная зона**.
2. Сначала сделайте **ZIP-бэкап**, если данные важны.
3. Выполните нужное действие и подтвердите.

## Структура данных на диске

Типичная папка библиотеки (активный корень):

```
Genealogy/
├── genealogy-data.json      # люди (schemaVersion + people)
├── external-entities.json   # справочник
├── tags.json                # метки
├── history.jsonl            # журнал действий
├── genealogy.sqlite         # лица, geocode cache
├── people/
│   └── {id}/
│       ├── photos.json
│       ├── bio.md
│       ├── avatar.jpg
│       ├── files/
│       └── photos/
│           ├── original/
│           ├── webp/
│           └── thumbs/
└── external/
    └── {id}/
        └── avatar.jpg
```

По умолчанию: `Documents/Genealogy` (или выбранное место хранения в настройках).
