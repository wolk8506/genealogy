# 🧬 Genealogy Desktop App

![](./build/icons/icon.png)

Приложение для ведения и визуализации семейной истории. Построено на базе Electron + React, с акцентом на автономность, приватность и удобство работы с мультимедийными данными.

## 🚀 Возможности

- 📁 **Импорт и экспорт данных** в формате `.zip` с сохранением структуры
- 🧑‍🤝‍🧑 **Управление людьми**: добавление, редактирование, перемещение в **корзину**
- 🖼️ **Фото и аватары**: поддержка изображений, встроенный просмотр и восстановление
- 📝 **Биографии** в формате Markdown с поддержкой встроенных изображений
- 🗃️ **Корзина**: восстановление или удаление людей и записей справочника, экспорт выбранных
- 📦 **Создание резервных копий (ZIP-бэкапов)** всех данных
- 🔍 **Поиск по имени и ID**
- 🧠 **Локальное хранение** — все данные остаются на вашем устройстве

## 🛠️ Технологии

- [Electron](https://www.electronjs.org/) — кроссплатформенный десктоп
- [React](https://reactjs.org/) + [MUI](https://mui.com/) — интерфейс
- [JSZip](https://stuk.github.io/jszip/) — работа с ZIP-бэкапами
- [file-saver](https://github.com/eligrey/FileSaver.js/) — сохранение файлов
- IPC и `preload.js` — безопасный мост между UI и файловой системой

## 📂 Структура ZIP-бэкапа

```
manifest.json
genealogy-data.json
external-entities.json
tags.json                 (опционально)
history.jsonl             (опционально)
genealogy.sqlite
people/
    └── 12345/
        ├── bio.md
        ├── avatar.jpg
        ├── photos.json
        └── photos/
            ├── original/
            ├── webp/
            └── thumbs/
external/
    └── E10001/
        └── avatar.jpg
```

## 🧪 Разработка

```bash
npm install
npm run dev
```

## 🖥️ Сборка

```bash
npm run build
```

## 📌 Особенности

- Приложение не требует подключения к интернету (кроме геокодинга и обновлений)
- Все данные хранятся локально в папке `Documents/Genealogy` или в выбранном месте хранения
- Поддержка восстановления **из бэкапа** с проверкой различий
- Возможность делиться отдельными людьми через экспорт
