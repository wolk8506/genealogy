# 🧬 Genealogy Desktop App

![](./build/icons/icon.png)

Приложение для ведения и визуализации семейной истории. Работает на Electron + React, хранит данные локально и не требует постоянного подключения к интернету.

## 🚀 Возможности

- 👪 **Люди**: карточки с родителями, братьями и сёстрами, супругами и детьми, поколениями и связями
- 🗓️ **События и факты**: хронология с датами, местами и участниками; справочные сведения о человеке
- 🖼️ **Фотографии**: личные альбомы и общая галерея, аватары с кадрированием, метаданные и теги
- 🎞️ **Файлы человека**: документы, аудио и видео рядом с профилем
- 📝 **Биографии** в Markdown: оглавление, поиск, печать и экспорт в PDF
- 🌳 **Генеалогическое дерево**: режимы «Потомки», «Предки», «Полное дерево», «Радиальное» и «Веер предков», подсветка родства
- 🏡 **Семьи**: каталог союзов, карточка семьи, даты и статусы брака по событиям
- 🧑‍🤝‍🧑 **Справочник**: внешние люди и питомцы, участники событий
- 🏷️ **Метки** и поиск по имени и ID
- 🕰️ **Лента времени** и 🗺️ **карта** событий
- 🗃️ **Корзина**: восстановление и окончательное удаление людей и записей справочника
- 📦 **Резервные копии**: экспорт и импорт ZIP с проверкой различий
- 🧠 **Распознавание лиц** локально, без облачных сервисов
- 🔔 **Уведомления** о событиях приложения
- ⭐ **«Это я»**: отметка домашнего человека для дерева, семей и стартового экрана
- 🧠 **Приватность**: все данные остаются на вашем устройстве

## 🛠️ Технологии

- [Electron](https://www.electronjs.org/) — кроссплатформенный десктоп
- [React](https://reactjs.org/) + [MUI](https://mui.com/) — интерфейс
- [Vite](https://vitejs.dev/) — сборка рендерера
- [React Router](https://reactrouter.com/) + [Zustand](https://zustand-demo.pmnd.rs/) — навигация и состояние
- [better-sqlite3](https://github.com/WiseLibs/better-sqlite3) — SQLite для лиц и кэша геокодинга
- [sharp](https://sharp.pixelplumbing.com/) + [archiver](https://github.com/archiverjs/node-archiver) — обработка медиа и ZIP-бэкапы
- [@vladmandic/face-api](https://github.com/vladmandic/face-api) — локальное распознавание лиц
- [Leaflet](https://leafletjs.com/) — карта, [Milkdown](https://milkdown.dev/) — редактор биографий
- IPC и `preload.js` — безопасный мост между UI и файловой системой

## 🧪 Разработка

```bash
npm install
npm run dev
npm test          # быстрые unit-тесты (без mock:library)
npm run test:full # полный прогон, включая mock:library и round-trip
```

Перед push желательно выполнить `npm test`; перед релизом — `npm run test:full` (см. [docs/maintenance/testing.md](docs/maintenance/testing.md)).
```

Тестовая библиотека с вымышленными людьми и местами создаётся командой:

```bash
npm run mock:library
```

Она появится в `Documents/Genealogy-Mock` — вне вашей настоящей библиотеки. Ключи `--out`, `--seed`, `--fresh` и `--help` описаны в [руководстве пользователя](./USER_GUIDE.md).

## 🖥️ Сборка

```bash
npm run build        # рендерер + установщик для текущей платформы
npm run dist:mac     # DMG, только Apple Silicon (arm64)
npm run dist:win     # NSIS
npm run dist:linux   # AppImage
```

Сборка macOS намеренно делает один arm64-артефакт: компьютеры на Intel не поддерживаются, и CI собирает ровно тот же `.dmg`, что и `npm run dist:mac`.

## 📌 Особенности

- Приложение не требует подключения к интернету, кроме геокодинга адресов и проверки обновлений
- Все данные хранятся локально в папке `Documents/Genealogy` или в выбранном месте хранения
- Семьи не хранятся отдельным файлом: они вычисляются из связей и событий брака
- Восстановление из бэкапа выполняется с проверкой различий
- Отдельными людьми можно делиться через экспорт
